# UniHub — النسخة المعاد تصميمها 🎨

**رفيقك الجامعي في مكان واحد** — تطبيق أندرويد أصلي (Kotlin + Jetpack Compose) لإدارة الملفات والمحاضرات والمهام والملاحظات والامتحانات. يعمل بالكامل دون إنترنت وتبقى بياناتك على جهازك.

هذه النسخة تطبق **إعادة التصميم الكاملة** لواجهات التطبيق بلغة Material 3 الحديثة بتخطيط هاتف عمودي (360dp × 800dp)، بعد اعتماد مقترحات التصميم المُلتقطة عبر Robolectric + Roborazzi بمحرك Skia الأصلي.

## ✨ ما الجديد في التصميم

| الشاشة | التحول الجوهري |
|---|---|
| **الرئيسية «مركز اليوم»** | بطاقة بطلة «الآن والتالي» بتدرج زمردي وشارة زجاجية للحالة الحية، وأقراص إحصاء قابلة للنقر، و«خط اليوم» الزمني الذي يدمج المحاضرات والمهام المستحقة في مسار واحد |
| **المخطط — المهام** | رقائق أقسام أفقية بدل شريط التبويبات الضخم، ترويسة واحدة تجمع العنوان والبحث وزر «مهمة» (بديل الزر العائم)، بطاقة تقدم بشريط إنجاز، خانة إنجاز دائرية مرسومة، وقسم منجزات منفصل |
| **الملفات** | حقل بحث دائري في المقدمة، بطاقة مساحة تخزين حقيقية (StatFs)، شبكة مجلدات 2×2 بأيقونات ملونة، وقرص نوع ملون لكل ملف يعرّفه قبل قراءة اسمه |
| **الإعدادات** | بنية «قائمة فلوحة»: فئات في قائمة مدمقة تنزلق لألواحها، بطاقات معاينة سمة مرسومة (فاتح/داكن/تلقائي) قبل الاعتماد، ولوحة ألوان الهوية |

## 🏗️ البنية التقنية

- **Jetpack Compose** + Material 3 — واجهة تصريحية بالكامل
- **Room** — قاعدة بيانات محلية (محاضرات، مهام، امتحانات، ملاحظات، ملفات، مجلدات)
- **Hilt** — حقن التبعيات
- **WorkManager** — النسخ الاحتياطي التلقائي المجدول
- **Navigation Compose** — تنقل آمن الأنواع
- **أرشيف ZIP** للنسخ الاحتياطي يشمل الملفات الفعلية

## 📦 الوحدات

- `app` — التطبيق الرئيسي بالشاشات المعاد تصميمها
- `design-proposals` — وحدة مقترحات التصميم: شاشات مرجعية ببيانات نموذجية ثابتة تُلتقط صورها من اختبارات JVM (Robolectric 4.14.1 + Roborazzi 1.26.0، محرك Native Skia، SDK 35، عربي RTL، شاشة هاتف عمودية 360dp×800dp بكثافة mdpi) — بلا محاكي إطلاقاً

```bash
# التقاط صور المقترحات:
./gradlew :design-proposals:recordRoborazziDebug
# المخرجات: design-proposals/build/outputs/roborazzi/*.png
```

## 🔨 البناء

```bash
./gradlew :app:assembleDebug     # نسخة التطوير
./gradlew :app:assembleRelease   # نسخة موقعة مصغرة (R8)
```

النسخة الموقعة تستخدم `app/keystore/unihub-release.jks` (تطبيق غير منشور).
R8/التصغير مُفعّل مع قواعد ProGuard التي تحفظ مُنشئات Room المولّدة (إصلاح Google الرسمي b/392657750).

## 🚀 التشغيل على جهازك

حمّل أحدث **APK** من [صفحة الإصدارات](../../releases) وثبّته مباشرة — لا يحتاج اتصالاً بالإنترنت إطلاقاً.
